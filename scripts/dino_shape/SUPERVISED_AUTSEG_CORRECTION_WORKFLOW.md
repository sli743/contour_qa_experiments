# Supervised real-autoseg correction QA

This experiment removes synthetic corruption from training. For each ROI, a frozen 3DINO encoder plus the existing lightweight decoder is trained on **real autosegmentation -> approved contour** pairs.

## Leakage control and localization

The crop center is derived only from raw autosegmentation masks using the same ROI-group center definitions as the legacy 1.5-mm ROIwise preprocessor. The approved contour is resampled only after the candidate-derived grid is fixed. Approved masks therefore supervise the target but do not localize the inference crop.

## Cross-validation

Patients are assigned once to 10 deterministic bins (seed 88). Five outer folds use two bins (20%) as test, one bin (10%) as validation, and the remaining seven bins (70%) as training. Every patient is an outer-fold test patient exactly once, and all reported OOF QA results are generated by a model that did not train or validate on that patient.

## Training

Input: actual autoseg contour. Target: approved contour. No synthetic corruptions are used. Loss is 0.40 global soft-Dice + 0.10 global BCE + 0.50 changed-region-weighted BCE, where the changed region is the real autoseg XOR approved mask (dilated 3 voxels, voxel weight +8). Encoder is frozen; decoder architecture and optimizer settings match NSR-QA where applicable.

## Run

1. Preprocess all active ROIs (replace 0-15 if active count differs):

```bash
sbatch -p hugo --account geoffrey_hugo --array=0-15%4 jobs/supervised_correction_preprocess_array.job
```

2. After preprocessing finishes, create CV manifests/configs:

```bash
source scripts/dino_shape/activate_3dino_env.sh
python scripts/dino_shape/prepare_supervised_autoseg_correction.py
```

3. Inspect the task count, then train all ROI/fold models:

```bash
N=$(($(wc -l < /scratch/shaohan/contour_QA/supervised_autoseg_correction/manifests/training_tasks.tsv)-1))
sbatch -p hugo --account geoffrey_hugo --array=0-$((N-1))%4 jobs/supervised_correction_train_array.job
```

4. After training finishes, evaluate all folds:

```bash
N=$(($(wc -l < /scratch/shaohan/contour_QA/supervised_autoseg_correction/manifests/training_tasks.tsv)-1))
sbatch -p hugo --account geoffrey_hugo --array=0-$((N-1))%2 jobs/supervised_correction_eval_array.job
```

5. Summarize:

```bash
bash scripts/dino_shape/summarize_supervised_correction_all_rois.sh
```

Held-out volumes are under `evaluations/<ROI>/fold_<k>/test_cases/patient_<id>/` and include CT, actual autoseg input, approved target, predicted approved contour, true missing/excess masks, and correction-added/removed masks.
